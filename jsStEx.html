Turn animation JSON into Stop Expressions

Paste a Bedrock or Blockbench animation file (.json). Each animation inside it gets its own Stop Expression, ready to copy. Requires the PHAM (Player Hijack Animation Module) setup, and only the supported variables are converted.

Animation JSON

Supported bones and variables
rootrotation x, z
position x, y, z v.root
waistrotation x, y, z
position x, y
scale xz, y v.body v.body_head.xzscale yscale
headrotation x, y, z
position x, y, z v.head
rightArm
leftArm		rotation x, y, z
position y v.rightarm v.leftarm
rightLeg
leftLeg		rotation x v.rightleg v.leftleg
bodyCan't be converted because v.body is only for waist.

The duration of each movement is the time between the current keyframe and the next one. For example, 0.3 to 0.5 is 0.2 seconds. A keyframe with the same value as the one before it doesn't add a segment, whatever that value is (0 or any other number).

Molang values are copied as they are. query. becomes q., variable. becomes v. and temp. becomes t..
